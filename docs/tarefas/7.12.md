# 🧪 Spec da tarefa 7.12: Unificar as ferramentas de Dev

| Tarefa | Itens | Fase | Status | Atualizado em |
|---|---|---|---|---|
| 7.12 | T2, T3 | 7 (Acesso aberto e histórico) | 📝 Proposta aguardando aprovação do usuário | 2026-10-31 |

## 1. Objetivo
Reduzir as 16 ferramentas de Dev a poucas, agrupadas por tipo de trabalho (como foi feito em Design), cada uma com abas, e redirecionar as páginas antigas.

## 2. Proposta (16 → 5)
| Nova ferramenta | Abas | Absorve |
|---|---|---|
| **Formatador de Dados e Código** | JSON (formatar, validar, comparar) · SQL/HTML/CSS/XML · CSV ↔ JSON · Markdown → HTML | json-formatter, formatador-codigo, csv-para-json, json-para-csv, markdown-para-html |
| **Codificadores** | Base64 · URL (codificar e analisar) · JWT | base64-encode, codificador-url, jwt-decoder |
| **Hash e UUID** | Hash (MD5…SHA-512) · UUID v4 · UUID em massa | hash-generator, uuid-generator, uuid-massa (hoje em Utilidades) |
| **Conversores Técnicos** | Bases numéricas · Timestamp Unix · Tabela ASCII · Unidades CSS | conversor-bases, unix-timestamp, tabela-ascii, css-units |
| **Regex e Cron** | Testador de Regex · Leitor de Cron | regex-tester, cron-helper |

## 3. Critérios de aceite (rascunho)
- [ ] CA1: cada ferramenta nova abre com as abas acima e mantém a lógica e os testes atuais.
- [ ] CA2: as 16 páginas antigas (e `uuid-massa`) redirecionam (308) para a aba certa.
- [ ] CA3: Dev passa a listar 5 ferramentas; sitemap e ícones acompanham.
- [ ] CA4: visual do layout novo (cabeçalho padrão, caixas com canto cortado, botões de 8 px, Phosphor).
